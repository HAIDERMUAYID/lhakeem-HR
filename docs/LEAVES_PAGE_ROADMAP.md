# خطة تطوير صفحة الإجازات | Leaves Page Roadmap

## نظرة عامة
خطة شاملة لتطوير صفحة الإجازات في نظام إدارة الحضور والإجازات — مركز الحكيم لأمراض الكلى.

---

## المرحلة 1: تحسين العرض والتفاصيل ✅

### 1.1 عرض المدة (أيام vs ساعات)
- **المشكلة:** الإجازات المُدخَلة بالأيام تظهر "١٤ ساعة" بدلاً من "٢ يوم"
- **الحل:** عرض المدة حسب المنطق:
  - إذا كانت المدة تعادل أيام كاملة (مضاعفات ٧ ساعات) → عرض بالأيام
  - إذا كانت ساعات جزئية (نصف يوم، ٣ ساعات...) → عرض بالساعات

### 1.2 زر التفاصيل
- إضافة زر "التفاصيل" لكل طلب إجازة
- فتح مودال/Sheet يعرض:
  - بيانات الموظف الكاملة
  - نوع الإجازة والرصيد المستخدم
  - التواريخ (بداية، نهاية، تاريخ المباشرة)
  - السبب (إن وُجد)
  - حالة الطلب وتاريخ الاعتماد/الرفض
  - من اعتمد/رفض الطلب

### 1.3 تحسين عرض البطاقات
- تصميم Card افقي أنظف مع أيقونات
- ألوان مميزة حسب نوع الإجازة أو الحالة
- عرض مختصر مع إمكانية التوسيع

## المرحلة 2: البحث والفلاتر الاحترافية ✅

### 2.1 شريط بحث رئيسي
- حقل بحث واضح في الهيدر (بحث بالاسم، القسم، نوع الإجازة)
- بحث فوري مع debounce (٣٠٠ms)
- أيقونة بحث واضحة

### 2.2 لوحة فلاتر محسّنة
- فلاتر افتراضية مرئية (الحالة، القسم، نوع الإجازة)
- فلتر التاريخ (من - إلى) بتصميم مدمج
- زر "مسح الكل" واضح
- عداد للفلاتر النشطة
- حفظ آخر الفلاتر (اختياري - localStorage)

### 2.3 خيارات العرض
- عدد الصفوف (١٠، ٢٥، ٥٠)
- ترتيب (الأحدث، الأقدم، الموظف، التاريخ)
- عرض: قائمة / جدول / بطاقات

---

## المرحلة 3: المخططات والإحصائيات 📊

### 3.1 مخطط دائري (Pie Chart)
- توزيع الطلبات حسب الحالة (معتمدة، قيد الانتظار، مرفوضة)
- أو توزيع حسب نوع الإجازة

### 3.2 مخطط أعمدة (Bar Chart)
- عدد الإجازات شهرياً (آخر ٦–١٢ شهراً)
- مقارنة بين أنواع الإجازات

### 3.3 مخطط خطي (Line Chart)
- اتجاه طلبات الإجازات عبر الزمن
- تنبؤ (اختياري)

### 3.4 ملخص سريع
- أكثر الموظفين إجازة
- أكثر الأقسام طلباً
- متوسط مدة الإجازة

---

## المرحلة 4: ميزات إضافية عملية

### 4.1 تصدير وتقارير
- تصدير القائمة الحالية إلى Excel
- طباعة الطلبات
- تقرير PDF حسب الفلتر

### 4.2 ربط بالتقويم
- رابط سريع لصفحة تقويم الإجازات
- معاينة شهرية مصغرة

### 4.3 إشعارات وتنبيهات
- تنبيه عند اقتراب رصيد الموظف من النفاد
- تنبيه للمدير عند طلبات جديدة

### 4.4 تحسينات UX
- Skeleton loading محسّن
- رسائل فارغة صديقة
- انتقالات سلسة (Framer Motion)
- دعم الوضع الليلي (إن وُجد)
